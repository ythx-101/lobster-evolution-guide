# Lobster Evolution Guide / 龙虾进化手册

**v1.0.0** | 2026-03-21

> 让你的 agent 从聊天机器人变成一个活的系统。

这份手册整理了 [OpenClaw](https://github.com/anthropics/claude-code) agent 系统的六大核心素养，帮助开发者搭建一个有生命力的 AI agent。

## 六大核心素养

| # | 素养 | 一句话 |
|---|---|---|
| 1 | **心跳** | 永不停歇的轮询循环，主动检查任务 |
| 2 | **外挂海马体** | 三层记忆架构（NOW.md + 记忆文件 + Git） |
| 3 | **工蜂调度** | 拆任务、派子 agent、并行干活 |
| 4 | **农场** | 想法是种子，衰减是筛选器，浇水是关注 |
| 5 | **自检与故障回流** | 降级链 + 进度日志 + 防抖检查 |
| 6 | **冥想与白日梦** | 定时反思 + 随机联想，灵感种进农场 |

## 怎么用

根据你的阶段挑对应部分看：

- **完全没概念** → 从心跳开始
- **agent 会失忆** → 看外挂海马体
- **干活太慢** → 看工蜂调度
- **想法太多** → 看农场
- **老出错** → 看自检与故障回流
- **想更聪明** → 看冥想与白日梦

每节都有可运行的代码示例、踩坑表格和练习题。
